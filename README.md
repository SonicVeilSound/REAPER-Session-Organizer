# REAPER-Session-Organizer
An expanded evolution of Reaper Brasil's Organizer for REAPER. Turn messy multitracks into a mix-ready session in one click: smart EN/IT track detection, auto stereo panning, unlimited folder nesting, custom colors, FX routing, per-preset FX chains, and built-in 0 VU (-18 dBFS RMS) gain staging with -6 dBFS peak protection.
